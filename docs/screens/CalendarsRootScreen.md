# Screen: CalendarsRootScreen

## Descripción
Contenedor principal para la sección de calendarios. Implementa la navegación por pestañas (Tabs) superiores para alternar entre "Calendarios" y la vista de "Eventos" globales.

## Funcionamiento
- Similar a `TasksRootScreen`, gestiona la navegación entre `DashboardScreen` (lista de calendarios) y `EventListScreen` (agenda de eventos).

## Endpoints Llamados
- Ninguno directamente.
